Personal Expense Tracker API

Manage your income and expense transactions. Use the panels below to send real HTTP requests to your running Spring Boot server.

Base URL:  http://localhost:8080/api/expenses
Methods:  GET · POST · PUT · DELETE
DB:  MySQL + JDBC

📥 Add Transaction
POST /api/expenses Create a new income or expense record ▾
Sends a JSON body with all required fields. The server auto-generates the id. Type must be exactly INCOME or EXPENSE.
📋 List Transactions
GET /api/expenses Get all — optional category & type filter ▾
All filters are optional. Leave blank to get all records. Combine both for narrow results.
🔍 Get One by ID
GET /api/expenses/{id} Fetch a single transaction by its UUID ▾
✏️ Update Transaction
PUT /api/expenses/{id} Replace all fields of an existing transaction ▾
All fields are required. The id in the URL identifies which record to update.
🗑️ Delete Transaction
DELETE /api/expenses/{id} Permanently remove a transaction ▾
⚠️ This action is permanent. The record will be deleted from MySQL and cannot be recovered.
🔎 Search by Title
GET /api/expenses/search Find transactions by title keyword (case-insensitive) ▾
Uses SQL LIKE %keyword% — partial matches work. E.g. lunch finds "Buy Lunch", "Office Lunch".
📅 Date Range Filter
GET /api/expenses/range Get transactions between two dates (inclusive) ▾
💵 Total Amount
GET /api/expenses/total Sum of all amounts, optionally by category ▾
Leave category empty to get the grand total across all transactions.
📊 Financial Summary
GET /api/expenses/summary Dashboard: total income, expenses & net balance ▾
Returns totalIncome, totalExpense, and netBalance (income − expense). No parameters needed.
